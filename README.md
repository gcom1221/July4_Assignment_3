# Macy 🤖 – AI Coding Assistant

Welcome to Macy – a fun and interactive AI-powered coding assistant built to help beginners learn programming step by step. This pretend open-source project combines conversational AI with practical code walkthroughs for HTML, CSS, JavaScript, and Python.

Whether you're just starting or need a buddy to debug your code, Macy is here for you.
